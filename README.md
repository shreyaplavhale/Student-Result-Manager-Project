# Student Manager App

A simple and modern Student Manager Web Application built using Flask, HTML, CSS, and Python.

This project allows users to manage student records easily through a clean and responsive web interface.

---

## Features

- Add Students
- View Student Records
- Check Student Result (Pass/Fail)
- Delete Student Records
- Responsive Modern UI
- Flask Backend Integration
- Dynamic Data Rendering

---

## Technologies Used

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- Jinja Templates
